## Definiteness — B pp. 196–207
Definite markers: **‑ەکە** (sg) / **‑ەکان** (pl); also **‑ە** (with an adjective, or after a demonstrative).
Indefinite: **‑ێک** (sg) / **‑ان** (pl).
How ‑ەکە attaches:
1. After a consonant: unchanged — دڵ+ەکە = دڵەکە، نان+ەکە = نانەکە، ژوور+ەکە = ژوورەکە.
2. After **ا / ۆ / ێ**: the ە drops, a y‑glide may appear — هەوا→هەواکە، چرا→چراکە; بڕۆ→بڕۆکە / بڕۆیەکە; ترێ→ترێکە، دێ→دێکە / دێیەکە، تانجێ→تانجێکەی.
3. After **ی**: ە drops, ی doubles in writing — شایی→شاییەکە، کانی→کانییەکە.
4. After **وو**: ە drops, وو stays — ئارەزوو→ئارەزووەکە، تەرازوو→تەرازووەکە، جوانوو→جوانووەکە.
5. After **ە**: the two ە's merge — سەرچاوە→سەرچاوەکە، شووشە→شووشەکە، پەنجەرە→پەنجەرەکە.
Plural ‑ەکان follows the same joins: مەلا→مەلاکان، شەهید→شەهیدەکان، بڕۆ→بڕۆکان، فەقێ→فەقێکان، چەرچی→چەرچییەکان، بەڕوو→بەڕووەکان، ئەستێرە→ئەستێرەکان، پشیلە→پشیلەکان.
Noun + adjective: definiteness goes on the **adjective**: کچە جوانەکە، کوڕە زیرەکەکە، بەردە گەورەکە (noun takes linking ‑ە). Predicative is different: کچەکە جوانە = "the girl is pretty".
Vocative/demonstrative ‑ە: ئەم کچە، ئەو کوڕە; دڵ+ە = دڵە (دڵە هەژار).
Definite = known to both speaker and hearer; indefinite ‑ێک = one unspecified item (پیاوێک هات).

## Izafe (نیشانەی ئیزافە) — B pp. 228–239
Marker is **‑ی** (Marf rejects the view that ‑ە or ‑ا are izafe markers in Sorani; the real izafe set in southern Kurmanji is ‑ی, with ‑ە only as a linking vowel before an adjective + definite).
1. After a consonant: ‑ی — سەر+ی = سەری، دەست+ی = دەستی، دامێن+ی = دامێنی، بەهار+ی = بەهاری، خەیاڵ+ی = خەیاڵی، پۆژ+ی = پۆژی.
2. After a vowel it sounds like /y/ and is still written ‑ی: مانگا→مانگای، چرا→چرای; بڕۆ→بڕۆی، دۆ→دۆی، ئاسۆ→ئاسۆی; خانوو→خانووی، ڕوو→ڕووی; ڕێ→ڕێی، کرێ→کرێی، پێ→پێی; پیاڵە→پیاڵەی، میوە→میوەی، خەندە→خەندەی، نەغمە→نەغمەی.
3. Izafe links head (دیارخراو) to modifier (دیارخەر): noun + noun (سەری فەرهاد), noun + adjective (بەهاری ڕووزەرد), noun + pronoun (دەستی من).
4. With plural: ‑ەکانی / ‑انی — پەرتووکەکانی نووسەر.

## Pronoun clitics (ڕاناوی لکاو) — A pp. 33–36
Set 1 (possessive, object of a preposition, agent of past transitive): ‑م/‑مان، ‑ت/‑تان، ‑ی/‑یان — کتێبم، خواردمان، لێم دیارە.
Set 2 (verb endings: present subject, past intransitive subject): ‑م/‑ین، ‑ی(ت)/‑ن، ‑ێت/‑ێ (present) ‑∅/‑ن (past) — ڕۆیشتم، دەچم، دەچێ(ت).
- Written standard 2nd sg is ‑یت, colloquial ‑ی; 3rd sg present written ‑ێت, spoken ‑ێ. Vowel‑final stems take ‑ات: دەکات، دەڕوات، دەخوات، دەبات.
- Past transitive agent = Set 1 (خواردم), past intransitive = Set 2 (ڕۆیشتم). Never *ڕۆیشتمان for "we ate".
- Independent: من، تۆ، ئەو / ئێمە، ئێوە، ئەوان. Reflexive: خۆم… خۆیان.

## Prepositions — A pp. 253–256
Simple: بە، لە، بۆ، تا، لەگەڵ، وەک، بێ، پێ، لێ، تێ. Circumposed: لە … دا / لە … ەوە / بە … ەوە. Absolute forms with clitic: پێم وت، لێی پرسی، تێی گەیشتم.

## Verb basics — A pp. 81–84
کار = action or state tied to time. تێپەڕ (takes object) vs تێنەپەڕ; auxiliaries بوون، هەبوون. Markers: present دە‑ (دەچم), negative نا‑ (ناچم), imperative/subjunctive بـ‑ (بچۆ، بچم), past negative نە‑ (نەچووم).

## House rules for Psoola copy (derived; keep consistent)
1. Kurdish Academy alphabet: ئ before an initial vowel (ئەم، ئێوە); ە for the short vowel; وو for /uː/ (پەرتووک، نووسەر، بوو); ێ، ۆ with their marks; ڕ، ڵ for the strong sounds (ڕۆژ، گوڵ، ماڵ، هەڵبژاردە).
2. Izafe always ‑ی, also after vowels: پەرتووکی نوێ، پسووڵەی نوێ، سینەمای سلێمانی، کۆنسێرتی ئەدنان کەریم.
3. Definite/indefinite per the join rules above: سینەماکە، پسووڵەیەک، بلیتەکان، ئاهەنگە تایبەتەکە.
4. Possessive clitic after the definite suffix: پەرتووکەکەت، بلیتەکەتان.
5. Questions: sentence + ؟ (…دەوێت؟); ئایا only in formal lines.
6. Currency: ١٠٠٠ دینار or 1000 IQD — one style per campaign.
7. Brand: PSOOLA / psoola.krd in Latin; Kurdish spelling پسووڵە.
